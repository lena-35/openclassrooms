# 🤖 Projet : Formation Openclassrooms

## 📝 Présentation du Projet
Ce dépôt centralise l'ensemble de ma formation technique.
L'objectif est de maîtriser et d'allier la programmation bas niveau, l'intelligence artificielle (RAG), la gestion d'infrastructure, le développement web et les bases de données pour créer un écosystème logiciel complet.
