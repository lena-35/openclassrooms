# 📑 Cours : Initiez-vous au Machine Learning (10h)
<<<<<<< Updated upstream

Ce cours d'initiation explore les techniques fondamentales du Machine Learning pour créer des modèles capables d'apprendre de manière autonome à partir de données.

## 🎯 Objectifs d'apprentissage
* **Appréhender** les grands principes du Machine Learning.
* **Manipuler** les fonctions de base d'un modèle prédictif.
* **Transformer** vos jeux de données pour améliorer l'apprentissage.
* **Optimiser** les performances et la robustesse des modèles.
=======
Ce cours permet de comprendre les principes fondamentaux de l'apprentissage automatique, de découvrir les principaux types d'algorithmes et d'apprendre à transformer des données pour optimiser la performance des modèles prédictifs.

## 🎯 Objectifs d'apprentissage
* Distinguer les notions de modèle, d'algorithme et les différents types d'apprentissage (supervisé, non supervisé).
* Évaluer la performance d'un modèle à l'aide de métriques adaptées.
* Maîtriser les algorithmes de base : régression linéaire, régression logistique et k-means.
* Transformer et préparer des jeux de données (nettoyage, sélection de variables, scaling).
* Améliorer la robustesse et la performance des modèles via l'apprentissage d'ensemble (Random Forests).

## 📚 Programme du cours

### Partie 1 - Découvrez les grands principes du Machine Learning
